# Plateforme de gestion des réseaux sociaux avec IA (MVP)

Spécification : `docs/cahier-des-charges.pdf`. Consignes de développement : `CLAUDE.md`.

## Démarrer en local

1. `npm install`
2. Copier `.env.example` en `.env.local` et remplir les valeurs.
3. `npm run dev` puis ouvrir http://localhost:3000

## Commandes

- `npm run dev` : serveur local
- `npm run build` : build de production
- `npm run lint` : vérification du code
